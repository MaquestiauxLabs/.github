# Contributing to MaquestiauxLabs

Thanks for your interest in contributing. This repository contains shared community health files used across MaquestiauxLabs repositories.

## Before You Start

- Read the [Code of Conduct](./CODE_OF_CONDUCT.md).
- Search existing issues and pull requests before opening a new one.
- Keep contributions focused and small when possible.

## Ways to Contribute

- Report bugs and documentation issues.
- Suggest improvements to standards, templates, and workflows.
- Submit pull requests for fixes and enhancements.

## Contribution Workflow

1. **Open or find an issue** describing the change.
2. **Fork** the repository and create a branch from `main`.
3. **Implement** the change with clear, minimal diffs.
4. **Validate** your changes locally.
5. **Open a pull request** and reference the issue.

## Branch Naming

Use descriptive branch names:

- `feat/<short-description>`
- `fix/<short-description>`
- `docs/<short-description>`
- `chore/<short-description>`

Examples:

- `docs/update-contributing-guide`
- `fix/correct-code-of-conduct-link`

## Commit Messages

Use clear, imperative commit messages:

- `feat: add contribution checklist`
- `docs: clarify pull request process`
- `fix: correct contact email in docs`

Tips:

- Keep the subject concise.
- Explain *why* in the body when context is not obvious.

## Pull Request Guidelines

Include the following in every PR:

- A clear summary of what changed and why.
- Linked issue (`Closes #123` when applicable).
- Scope kept to one logical change.
- Updated documentation when behavior/process changes.

### PR Checklist

- [ ] I read and follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
- [ ] My change is focused and minimal.
- [ ] I verified links and formatting in modified docs.
- [ ] I updated related documentation if needed.
- [ ] I referenced the related issue (if applicable).

## Review Expectations

- Be respectful and constructive in reviews.
- Address feedback with follow-up commits.
- Prefer discussion over force-push rewrites after review starts (unless requested).
